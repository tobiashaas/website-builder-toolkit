## Ideas, not copied

These works shaped the approach. No text or code from them is included; where they are relevant, the docs link to them.

- [charles-skills](https://github.com/LemonFace0309/charles-skills) by Charles Liu: charles-polish and charles-unreasonable-craft, which build on Emil Kowalski's design engineering material and Josh Puckett's Interface Craft.
- [Gearyco Agentic Toolkit for Etch](https://github.com/kevingeary/gearyco-agentic-toolkit-for-etch) by Kevin Geary: the shape of a tool-agnostic `AGENTS.md` with context modules.
- [mattpocock/skills](https://github.com/mattpocock/skills) by Matt Pocock (MIT): the structure of small composable skills, a router skill, a shared glossary, a scope file, interviews in rounds with a recommended answer, and plugin packaging.
- [Bricks Builder](https://bricksbuilder.io) agent skills and documentation.
- [Automatic.css](https://automaticcss.com) documentation.
